## Описание

Эта программа демонстрирует способ удаления элемента из среза (slice) в Go по указанному индексу.

## Реализация

Для удаления элемента с индексом `i` из среза `s` используется следующий подход:
1.  Берется часть среза до элемента `i` (`s[:i]`).
2.  Берется часть среза после элемента `i` (`s[i+1:]`).
3.  Эти две части объединяются с помощью встроенной функции `append`.

Пример кода:
```go
func removeElement(slice []int, i int) []int {
    return append(slice[:i], slice[i+1:]...)
}
```

Этот метод эффективен, так как он создает новый срез, переиспользуя память исходного, и не требует ручного копирования элементов в цикле.

## Как запустить

```bash
go run L1.23.go
```
